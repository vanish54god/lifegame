# 🎮 LifeGame: геймификация жизни

Вечером ты **админ**: настраиваешь квесты на завтра. Утром ты **игрок**: выполняешь их и получаешь XP.
За XP растут уровни, за монеты покупаешь награды в магазине.

**Что внутри (все 5 этапов):**
- 🤖 **Telegram-бот:** всё на кнопках. Отметки квестов, пошаговое добавление (категория → XP → название), шаблоны, магазин, профиль, напоминания.
- 📱 **Веб-приложение (PWA):** ставится на экран iPhone/iPad как приложение. Вкладки: Сегодня, Админ, Статы (графики по дням и неделям, карта активности, категории, достижения), Магазин, Настройки.
- 🔥 Серии дней, 🏆 13 достижений, «ЗАДАНИЕ ВЫПОЛНЕНО» на весь экран.
- 🌙 Стиль: ночной город, натриевые фонари, плёночное зерно.

Бот и приложение работают с одной базой, поэтому прогресс везде одинаковый.

## Запуск на ноуте (Windows)

1. Поставь Python 3.11+ с [python.org](https://www.python.org/downloads/) (галочка **Add python.exe to PATH**).
2. Открой папку проекта, кликни в адресную строку проводника, напиши `powershell` и нажми Enter.
3. Один раз:
   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   copy .env.example .env
   ```
   Если PowerShell ругается на скрипты: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повтори.
4. Создай бота: в Telegram **@BotFather** → `/newbot` → токен вставь в `.env` в `BOT_TOKEN`.
5. Запусти `start.bat` (или `py main.py`). Напиши боту что угодно, и он пришлёт твой ID.
6. Впиши ID в `.env` как `OWNER_ID`, закрой окно и снова запусти `start.bat`. Жми `/start`.

Дальше просто запускай `start.bat`.

### Веб-приложение на ноуте

В боте: **🛠 Админ → 🌐 Веб-приложение**. Бот даст код, открой http://localhost:8000 и введи его.

**С iPad/iPhone в той же Wi-Fi сети:** узнай IP ноута (`ipconfig` → IPv4, например `192.168.1.5`) и открой `http://192.168.1.5:8000`.
Windows спросит про доступ для Python в сети, разреши для **частных** сетей.
Поставить на экран «Домой» как настоящее приложение получится только с HTTPS, то есть уже на VPS (см. [DEPLOY.md](DEPLOY.md)).

> ⚠️ `.env` (токен) и `game.db` (прогресс) не заливай на GitHub. Они уже в `.gitignore`.

## Бот

Внизу постоянная клавиатура:

| Кнопка | Что делает |
|---|---|
| 🎮 Сегодня | квесты дня: ✅ выполнено, ❌ провалено, ↩️ отменить; ➕ квест, 📋 шаблон |
| 👤 Профиль | уровень, серия, монеты, достижения |
| 🛠 Админ | квест на завтра/сегодня, шаблоны, план, вчера, вход в приложение |
| 🛒 Магазин | награды и покупка с подтверждением |

Быстрые команды: `/add учеба 300 Лаба`, `/bonus 50 Разобрать стол`, `/addnow`, `/bonusnow`, `/item 300 Квест-комната`, `/web`, `/logout_all`, `/rules`.

## Правила

Весь баланс лежит в `app/rules.py`: поменял число, перезапустил, готово.

- **Основные** (1–3 в день): учёба 100–500, работа 100–500, ГУТВ 50–500, сон до 100, программирование 50–200.
- **Бонусные:** 10–200, без лимита.
- Границы мягкие: за ультра хард можно дать больше.
- **Уровни:** на 1-й нужно 100 XP, дальше каждый на 50 больше.
- **Монеты** = XP / 10 минус покупки. Уровень от покупок не падает.
- **Серия:** день засчитан, если все основные квесты выполнены. Сегодняшний день серию не рвёт, пока не закончился.
- Игровой день начинается в **5:00**, так что «лёг в 00:30» засчитается во вчерашний день.

## Напоминания

Настраиваются в приложении: **Настройки → Напоминания**. Утром бот присылает квесты дня, вечером зовёт в админку. Пустое поле значит, что напоминания нет.

## Структура

```
main.py            — запуск: бот + веб + напоминания в одном процессе
start.bat          — запуск на Windows двойным кликом
app/rules.py       — правила и баланс
app/game.py        — вся игровая логика (квесты, шаблоны, магазин, статистика, достижения)
app/db.py          — база SQLite (+ автообновление старой базы)
app/auth.py        — вход по одноразовому коду
app/bot.py         — Telegram-бот
app/web.py         — API для приложения
web/               — само приложение (HTML/CSS/JS без сборки)
tests/             — тесты: pip install -r requirements-dev.txt, потом py -m pytest
Dockerfile, docker-compose.yml, Caddyfile — для VPS
DEPLOY.md          — как задеплоить
```
